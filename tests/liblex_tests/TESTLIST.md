# Список тестов

## Класс TextScanner

- [x] Чтение символов с предпросмотром вперёд и сдвигом позиции: `the\nend`
- [x] Подсчёт строк и колонок для переносов `\n`, `\r\n`, `\r`
- [x] Колонка считается в символах Unicode, а не в байтах: `ёж`
- [x] Захват текста от начала токена до текущей позиции

## Функция ReadSourceFile

- [x] Загрузка файла в память без изменения переносов строк
- [x] Исключение при чтении несуществующего файла

## Функция ToString

- [x] Название типа токена, в том числе конца файла

## Класс Lexer

### Идентификаторы и ключевые слова

- [x] Пустой текст: только конец файла
- [x] Разбор идентификаторов: `alice Bob C00L d_2 _x x`
- [x] Идентификатор из одних подчёркиваний недопустим: `_ __`
- [x] Символы вне ASCII недопустимы в идентификаторе: `имя`
- [x] Ключевые слова управления потоком: `if else while do for in break continue return`
- [x] Ключевые слова объявлений: `fun struct val var`
- [x] Логические литералы: `true false`
- [x] Названия типов: `Int Double Boolean Char String Unit Array`
- [x] Ключевые слова чувствительны к регистру: `int If WHILE`
- [x] Зарезервированные слова недопустимы: `as catch class ... when`
- [x] Ключевое слово — префикс идентификатора: `iffy fun_ values Integer classes`

### Литералы чисел

- [x] Десятичные литералы: `0 42 2147483647`
- [x] Подчёркивания между цифрами: `1_000 1__0 12_34_56`
- [x] Шестнадцатеричные и двоичные литералы: `0xFF 0x7fff_ffff 0x0 0b101 0b1_0`
- [x] Литерал целого вне диапазона Int: `2147483648 0x80000000 0b1000...`
- [x] Десятичный литерал с ведущим нулём недопустим: `007 0_1 00`
- [x] Подчёркивание не на месте и литерал без цифр: `1_ 0x_1 0x 0b`
- [x] Сразу после литерала не может идти буква, цифра или `_`: `12abc 0b102 0xFG 0XFF 7_x`
- [x] Вещественные литералы: `1.5 0.25 3.0 1_000.000_5`
- [x] Экспонента: `2.5e-3 1E10 1e3 1e+2 0e0`
- [x] Неполная экспонента и буква после литерала недопустимы: `1e 2.5E 3.5x 1e5_`
- [x] Ведущий ноль недопустим и в вещественном литерале: `00.5 01e2`
- [x] Точка без цифр не относится к литералу: `.5 5. 1..2 1.foo`
- [x] Вещественный литерал вне диапазона Double: `1e400 1.0e-400`

### Литералы символов

- [x] Простые символы: `'a' ' ' '"' '/'`
- [x] Символ Unicode вне ASCII: `'ж' '€' '😀'`
- [x] Escape-последовательности: `'\n' '\t' '\r' '\b' '\'' '\"' '\\' '\$'`
- [x] Escape-последовательности Unicode: `'\u0041' '\u{1F600}' '\u{41}'`
- [x] Пустой литерал и литерал из двух символов недопустимы: `'' 'ab' 'жж'`
- [x] Незакрытый литерал символа: `'a` и `'a` с переносом строки
- [x] Неверные escape-последовательности: `'\q' '\u12' '\u{}' '\u{1234567}' '\u{110000}' '\uD800'`
- [x] Незакрытая фигурная скобка в `\u{...}`
- [x] Недопустимая последовательность байт UTF-8 в литерале символа

### Литералы строк

- [x] Пустая строка: `""`
- [x] Простая строка: `"Hello, world!" "x"`
- [x] Строка с символами вне ASCII: `"Привет, 😀"`
- [x] Escape-последовательности в строке: `"\n\t\r\b\"\'\\\$"`
- [x] Unicode escape-последовательности в строке: `"\u0416\u{1F600}"`
- [x] Неверная escape-последовательность в строке не прерывает её разбор: `"a\qb"`, `"\u{110000}\u12"`
- [x] Подстановка переменной: `"x = $x" "$a$b_1!" "\$x"`
- [x] Имя из одних подчёркиваний в подстановке недопустимо: `"$_ $__"`
- [x] Знак `$` без имени — обычный символ: `"$ $1 $"`
- [x] Подстановка выражения: `"${x * 2}"`
- [x] Подстановка с вложенной строкой: `"a${f("b$c")}d"`
- [x] Подстановка с блоком внутри: `"${ {a} }"` — закрывающая `}` блока не завершает подстановку
- [x] Незакрытая подстановка: `"${a`
- [x] Незакрытая строка до конца файла: `"abc`
- [x] Строка не может содержать перенос строки, в том числе `\r\n`: `"abc` + `\n` + `x`

### Операторы

- [x] Арифметические операторы: `+ - * / %`
- [x] Операторы сравнения: `== != === !== < > <= >=`
- [x] Логические операторы: `&& || !`
- [x] Одиночные `&` и `|` недопустимы
- [x] Операторы присваивания: `= += -= *= /= %=`
- [x] Инкремент и декремент: `++ --`
- [x] Самая длинная лексема: `a+++b a====b!==c`
- [x] Доступ к полю и диапазоны: `. .. ..< ...`
- [x] Принадлежность: `in !in`
- [x] `!in` с продолжением идентификатора: `!inside !_in`
- [x] Недопустимые символы: `? @ # \` и обратная кавычка

### Скобки и разделители

- [x] Скобки: `( ) { } [ ]`
- [x] Угловые скобки типа массива: `Array<Array<Int>>`
- [x] Разделители: `, : ;`

### Переводы строк

- [x] Перевод строки между инструкциями — разделитель
- [x] Несколько переводов строк подряд дают один разделитель
- [x] Переводы строк в начале и в конце файла не являются разделителями
- [x] Переводы строк `\r\n` и `\r` тоже являются разделителями
- [x] Перевод строки внутри `( )` и `[ ]` не является разделителем, несовпадающая закрывающая скобка не закрывает контекст
- [x] Перевод строки внутри `{ }` является разделителем
- [x] Перевод строки внутри `${ }` не является разделителем
- [x] Перевод строки после бинарного оператора, `.`, `,`, `:`, `(`, `[`, `{`, `in`, `!in`, `else`, `do` не является разделителем
- [x] Перевод строки после `++` и `--` является разделителем
- [x] Перевод строки после `)` заголовка `if`, `while`, `for` не является разделителем
- [x] Перевод строки после `)` вызова функции является разделителем
- [x] Перевод строки перед `.`, `else`, `&&`, `||` не является разделителем
- [x] Перевод строки перед `..` и `elseif` является разделителем
- [x] Перевод строки рядом с `;` не даёт дополнительного разделителя

### Пробелы и комментарии

- [x] Пропуск пробельных символов: пробел, `\t`, `\r`, `\n`
- [x] Однострочный комментарий до конца строки, в том числе после оператора
- [x] Однострочный комментарий в конце файла
- [x] Блочный комментарий, `*/` вне комментария — это операторы
- [x] Вложенные блочные комментарии
- [x] Блочный комментарий с переводом строки является разделителем
- [x] Незакрытый блочный комментарий
- [x] Символы комментариев внутри строки не являются комментарием: `"// /* 'a' */"`

### Позиции токенов

- [x] Позиции токенов в многострочной программе
- [x] Позиции ошибок: литерал символа, незакрытая строка, незакрытый комментарий
- [x] Позиция разделителя-перевода строки — позиция первого перевода строки
