# Компилятор языка S-lop на C++26

S-lop - это статически типизированный учебный язык программирования.

* Цель этого проекта — написать компилятор на C++26 с VM

## Сборка и запуск

Этот проект написан на C++23:

1. Для сборки используется CMake: см. [docs/setup/cmake.md](docs/setup/cmake.md)
2. Установка пакетов, необходимых для сборки, описана в [docs/setup/llvm.md](docs/setup/llvm.md)
3. Компилятор вызывает `gcc` для компоновки, путь к `gcc` должен быть в PATH
4. Сборка проверена с GCC 13.3 на Ubuntu GNU/Linux.

Для удобства написан Makefile, но он необязателен. Примеры использования Makefile:

```bash
# Установка, конфигурирование, сборка и запуск тестов в конфигурации Debug
make

# Установка, конфигурирование, сборка и запуск тестов в конфигурации Release
make BUILD_TYPE=Release

# Конфигурирование пакетов (конфигурация Debug)
make cmake

# Форматирование кода
make format
```
