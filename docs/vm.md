# Спецификация виртуальной машины S-lop

Стековая виртуальная машина S-lop разработана под потребности текущей реализации интерпретатора.

## Структура

| Компонент   | Назначение                                                   |
| ----------- | ------------------------------------------------------------ |
| Program     | Список инструкций, составляющих программу                    |
| IP          | Instruction pointer, индекс следующей инструкции в программе |
| Values      | Стек для вычисления выражений                                |
| Environment | Абстракция для доступа к потокам stdin/stdout/stderr         |

## Инструкции

| Инструкция | Операнд | Эффект для стека            | Описание                                                  |
| ---------- | ------- | --------------------------- | --------------------------------------------------------- |
| halt       | —       | —                           | Останавливает выполнение программы                        |
| push       | N       | ... → ... N                 | Помещает число N на вершину стека                         |
| add        | —       | ... left right → ... result | Сложение: `result = left + right`                         |
| subtract   | —       | ... left right → ... result | Вычитание: `result = left - right`                        |
| multiply   | —       | ... left right → ... result | Умножение: `result = left * right`                        |
| divide     | —       | ... left right → ... result | Целочисленное деление: `result = left / right`            |
| negate     | —       | ... value → `... result     | Смена знака: `result = -value`                            |
| println    | —       | ... value → ...             | Печатает `value` и перенос строки в поток вывода          |
| read       | —       | ... → ... result            | Читает байт из потока ввода и кладёт в стек его ASCII-код |

## Модель выполнения

На каждом шаге выполнения виртуальная машина:

- выбирает инструкцию по индексу IP;
- увеличивает IP;
- вычисляет инструкцию к стеку операндов.

Выполнение останавливается инструкцией `halt` или по достижении конца программы.
