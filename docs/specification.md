# Язык S-lop

- Исходный текст - файл в кодировке UTF-8. 
- Перевод строки - `\n`, `\r\n` или одиночный `\r`.

> [!TIP]
> Из нескольких подходящих лексем выбирается самая длинная, учитываются только корректные лексемы:
> `1..2` читается как `1`, `..`, `2`, а `5.toString()` - как `5`, `.`, `toString`, `(`, `)`.
> Последовательность символов, которую нельзя разбить на лексемы считаем *лексической ошибкой*.

## Ключевые слова

Ключевые слова чувствительны к регистру. Например, `Array` считается ключевым словом, а `array` - идентификатором.

| Слово    | Предназначение                                                      |
|----------|---------------------------------------------------------------------|
| break    | Прерывание цикла                                                    |
| continue | Переход к следующей итерации цикла                                  |
| do       | Начинает цикл с постусловием                                        |
| else     | Отделяет ветку else в ветвлении                                     |
| false    | Логическое значение «ложь»                                          |
| for      | Начинает цикл с итерацией                                           |
| fun      | Начинает объявление функции                                         |
| if       | Начинает ветвление                                                  |
| in       | Отделяет переменную цикла for от диапазона; проверка принадлежности |
| return   | Возврат из функции                                                  |
| struct   | Начинает объявление структуры                                       |
| true     | Логическое значение «истина»                                        |
| val      | Объявление неизменяемой переменной или поля                         |
| var      | Объявление изменяемой переменной или поля                           |
| while    | Начинает цикл с условием                                            |

Названия типов тоже являются ключевыми словами:

| Слово   | Предназначение                                   |
|---------|--------------------------------------------------|
| Int     | Целочисленный 32-битный тип                      |
| Double  | Вещественный 64-битный тип                       |
| Boolean | Логический тип                                   |
| Char    | Символ                                           |
| String  | Строка                                           |
| Unit    | Тип результата функции, не возвращающей значения |
| Array   | Массив, например `Array<Int>`                    |

Слова `as`, `catch`, `class`, `finally`, `import`, `interface`, `is`, `null`, `object`, `package`, `super`, `this`,
`throw`, `try`, `typealias`, `typeof`, `when` - в языке не используются, 
но и применять их как идентификаторы нельзя (зарезервированно).

Имена встроенных функций (`print`, `println`, `readln`, `arrayOf`, `exit`) лексически являются идентификаторами, 
но объявлять символы с такими именами нельзя.

| Оператор | Предназначение                              |
|----------|---------------------------------------------|
| .        | Доступ к полю структуры или члену значения  |
| +        | Сложение, унарный плюс, конкатенация строк  |
| -        | Вычитание, унарный минус                    |
| *        | Умножение                                   |
| /        | Деление                                     |
| %        | Остаток от деления                          |
| ==       | Сравнение "равно"                           |
| !=       | Сравнение "не равно"                        |
| ===      | Сравнение ссылок "тождественно"             |
| !==      | Сравнение ссылок "не тождественно"          |
| <        | Сравнение "меньше"                          |
| >        | Сравнение "больше"                          |
| <=       | Сравнение "меньше или равно"                |
| >=       | Сравнение "больше или равно"                |
| &&       | Логическое "и"                              |
| \|\|     | Логическое "или"                            |
| !        | Логическое "не"                             |
| ..       | Диапазон, верхняя граница включена          |
| ..<      | Диапазон, верхняя граница исключена         |
| in       | Проверка принадлежности                     |
| !in      | Проверка непринадлежности                   |
| =        | Присваивание                                |
| +=       | Присваивание со сложением                   |
| -=       | Присваивание с вычитанием                   |
| *=       | Присваивание с умножением                   |
| /=       | Присваивание с делением                     |
| %=       | Присваивание с остатком                     |
| ++       | Инкремент                                   |
| --       | Декремент                                   |

Особенности:

- `!in` - один оператор, если `in` не продолжается идентификатором: `!init` - это `!` и `init`
- `...` читается как `..` и `.`
- `++` и `--` всегда одна лексема и допустимы только как инструкция: `--x`, `a--b`, `a+++b` - ошибки;
  двойной минус - `- -x`
- Символы `?`, `@`, `#`, `\` и обратная кавычка вне строк и комментариев недопустимы

## Виды скобок

| Оператор | Предназначение                                                                           |
|----------|------------------------------------------------------------------------------------------|
| ( )      | Для смены приоритета, объявления/вызова функций и конструкторов, заголовков if/while/for |
| { }      | Для блоков, тел функций и подстановок `${...}` в строках                                 |
| [ ]      | Для доступа к элементу массива или строки                                                |
| < >      | Для указания типа элементов массива: `Array<Int>`                                        |

Угловые скобки - это лексемы `<` и `>`. Лексер не видит разницы между ними и операторами сравнения. 
При разборе типа может возникнуть ситуация, когда ожидается закрывающая `>`, 
а лексер выдал `>=`, синтаксический анализатор воспринимает её как: `>` и `=`.

## Разделители

| Оператор             | Предназначение                            |
|----------------------|-------------------------------------------|
| ,                    | Разделитель аргументов, параметров, полей |
| :                    | Разделитель для описания типа символа     |
| ; или перевод строки | Разделитель последовательности инструкций |

Перевод строки неявляется разделителем, если:

1. Ближайшая открытая скобка - `(` или `[`. Внутри `{ }`, даже вложенных в `( )`, 
переводы строк снова разделяют инструкции
2. Предыдущий токен - бинарный или присваивающий оператор, `.`, `,`, `:`, `(`, `[`, `{`, `in`, `!in`, `else`, `do`,
закрывающая скобка заголовка `if`/`while`/`for` или `}` тела `do`
3. Следующий токен - `.`, `else`, `&&` или `||`

Несколько разделителей подряд считаются одним. Тело функции (`{` или `=`) должно начинаться на той же
строке, что и конец заголовка, иначе это ошибка.

## Идентификаторы

Идентификатор - это последовательность английских букв, арабских цифр и подчёркиваний.

- Начинается с буквы или подчёркивания;
- Не может состоять только из подчёркиваний;
- Регистр имеет значение.

## Литералы

1. Литералы целых чисел:
    - десятичные (`67`), шестнадцатеричные (`0xFF`) и двоичные (`0b011`), префикс в любом регистре
    - `_` допускается только между цифрами
    - десятичный литерал не начинается с `0`, кроме самого `0`
    - значение не превышает `2147483647`; отрицательные числа - через минус
    - сразу после литерала не может следовать буква, `_` или цифра другой системы счисления
2. Литералы вещественных чисел:
    - цифры обязательны по обе стороны от точки: `1.7` (`.7` и `7.` недопустимы)
    - допускается экспонента: `1.7e-3`, `1E10`, `1e3`
    - `_` недопустим
    - переполнение до бесконечности (`1e400`) - ошибка, округление к нулю (`1e-400`) даёт `0.0`
3. Литералы логических значений: `true`, `false`
4. Литералы символов в одинарных кавычках `'`, содержат одну кодовую точку Unicode или escape-последовательность:
   `'a'`, `'\n'`, `'🩶'`, a `'`, `\` и перевод строки - только через escape-последовательность
5. Литералы строк в двойных кавычках `"`, содержат символы, escape-последовательности и подстановки:
    - строка, включая подстановки, целиком располагается на одной строке

Незакрытый литерал символа или строки - лексическая ошибка.

Варианты escape-последовательностей (для строк и символов):

| Вариант   | Значение                                                    |
|-----------|-------------------------------------------------------------|
| \\n       | Перенос строки                                              |
| \\t       | Табуляция                                                   |
| \\r       | Возврат каретки                                             |
| \\b       | Backspace                                                   |
| \\"       | Двойная кавычка                                             |
| \\'       | Одинарная кавычка                                           |
| \\\\      | Обратный слэш                                               |
| \\$       | Знак доллара                                                |
| \\uXXXX   | Символ Unicode, X - шестнадцатеричная цифра (ровно 4 цифры) |
| \\u{X...} | Символ Unicode, от 1 до 6 шестнадцатеричных цифр            |

- Значение `\u` должно быть кодовой точкой от `0` до `10FFFF`, кроме суррогатов `D800`-`DFFF`, иное значение -
  лексическая ошибка.
- Любая другая последовательность, начинающаяся с `\`, также лексическая ошибка.

### Подстановки в строках

- `$param` - значение переменной `param` читается до первого символа, не являющегося буквой, цифрой или `_`.
Имя не может состоять только из подчёркиваний (`"$__"`), а `"$param.text"` подставляет `param`, за которым идёт текст `.text`
- `${expression}` - значение выражения; подстановка завершается `}`, парной открывающей `{`, с учётом вложенных
  `{ }` и строк: `"${if (a) { 6 } else { 7 }}"`
- `$`, после которого нет буквы, `_` или `{`, - обычный символ: `"$5"`, `"cost: $"`

Пример: `"x = $x, x * 2 = ${x * 2}"`

## Пробелы и комментарии

Игнорируются пробелы, `\t`, `\r` и `\n` (кроме случаев, когда перевод строки - разделитель).

- Однострочные комментарии: от `//` до конца строки
- Блочные комментарии: от `/*` до `*/`, могут быть многострочными и вложенными; незакрытый - ошибка
- Комментарий с переводом строки считается одним переводом строки
- Внутри литералов `//` и `/*` не начинают комментарий
